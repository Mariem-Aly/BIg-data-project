# Big-data-project
# E-Commerce Sales Analytics Using Big Data Technologies

## Project Overview
This project analyzes an e-commerce sales dataset using Big Data technologies. The project covers the complete data pipeline from data ingestion to visualization.

## Objectives
- Clean and preprocess the dataset.
- Analyze customer purchasing behavior.
- Build machine learning models.
- Visualize business insights.

## Technologies Used
- Apache Hadoop (HDFS)
- Apache Flume
- Apache Spark (PySpark)
- Python
- Git & GitHub

## Project Workflow

CSV Dataset >> Apache Flume >> HDFS >> Apache Spark (ETL & Processing) >> Machine Learning >> Visualization

## Project Structure

```
project/
│
├── data/
├── ETL.py
├── processing.py
├── models.py
├── visualization/
├── README.md
```

## How to Run

1. Upload the dataset.
2. Run Flume to ingest the data into HDFS.
3. Execute the Spark ETL scripts.
4. Run the machine learning models.
5. Open the visualization dashboard.

## Expected Results
- Cleaned dataset.
- Analytical insights.
- Machine learning results.
- Interactive dashboard.
